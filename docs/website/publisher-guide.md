# Publisher Quick Start

Use VoxelAds to display chat ads on a Minecraft server you operate and earn from validated impressions.

## Connect your server

1. Sign up with email or Google and choose **Publisher** during setup. If you registered with email, verify your address.
2. In **Servers**, add your server name, host, and category. Copy the one-time setup token before leaving the setup page and keep it private. If it expires, generate a new token from server details.
3. Before enabling the integration, tell players what it does and what data it sends. Follow the [Advertising & Server Rules](advertising-and-server-rules.md) and review the [Privacy Policy](privacy.md). The integration can send player data before advertising starts.
4. When you have access to the VoxelAds plugin, install it and use the setup token to activate the connection. The plugin download and installation instructions are currently unavailable in the workspace. The setup page shows the activation status and lets you check it manually.
5. Check **Server review** in server details. New servers go to moderator review after activation. If your server is rejected, correct the issue and select **Resubmit for review**. If you change your server’s host, it will need review again.

## Check advertising and payouts

Ads can serve once the server is connected, approved, and enabled and your publisher account is active. Available ads also depend on eligible campaigns matching your audience. From server details you can check connection status, review decisions, and performance.

Open **Payouts** to see pending earnings, eligible balance, the current payout minimum, the hold period, and the estimated payout window. Earnings are based on validated impressions. Payout amounts are shown in USD and dates are shown in UTC. Stripe Connect setup is currently unavailable in the workspace.

## Sample notice for players

Adapt this notice to how your server actually uses the integration and place it where players can see it before any data is sent.

> This server uses VoxelAds to display ads in Minecraft chat. The integration may send VoxelAds a coded player identifier, a session identifier, country and language when available, and information about which ads were displayed. VoxelAds uses this information to select ads, limit repeat ads, and measure and verify delivery. If you open a VoxelAds ad link, VoxelAds records click activity before sending you to the advertiser’s site. See the [VoxelAds Privacy Policy](privacy.md) and [your server’s privacy notice] for more information and contact details.
