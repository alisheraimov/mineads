# Advertiser Quick Start

Use VoxelAds to run text ads in chat on participating Minecraft servers.

## Create and submit your first ad

1. Sign up with email or Google and choose **Advertiser** during setup. If you registered with email, verify your address.
2. In **Campaigns**, create a campaign. Enter its name, start and end times in UTC, target countries, server categories, and daily and total budgets in USD. Review your settings and submit the campaign.
3. In **Creatives**, create a creative for that campaign. Enter the chat message, set its language if applicable, and optionally add a destination URL. Check the chat preview, then select **Submit for review**. See the [Advertising & Server Rules](advertising-and-server-rules.md) before submitting.
4. Check the creative’s review status. If it is rejected, use the review feedback to update it. Changes to approved ad text, destination URL, or language require another review.

## Check delivery and spend

A campaign can deliver during its scheduled window when it is active, has an approved and unpaused creative, has eligible players on participating servers, and has sufficient budget and balance. If you see no impressions, start with those checks. You can pause a campaign from its details page.

Use the campaign details to check validated impressions, spend, and clicks. Validated impressions drive charges. Clicks help you measure engagement with linked ads. In **Billing & funding**, check your available balance and monthly activity. Online funding is currently unavailable in the workspace.
